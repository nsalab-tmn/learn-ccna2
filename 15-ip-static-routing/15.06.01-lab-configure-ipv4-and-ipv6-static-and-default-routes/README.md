## Описание сценария

Статический маршрут задает путь к сети вручную: через адрес следующего перехода, через выходной интерфейс маршрутизатора (напрямую подключенный статический маршрут) или через оба сразу. Статический маршрут по умолчанию ведет ко всем сетям, для которых в таблице маршрутизации нет более точного маршрута, а статический маршрут узла ведет к одному адресу: с маской 255.255.255.255 в IPv4 и с длиной префикса /128 в IPv6. Плавающий статический маршрут — резервный: его административное расстояние больше, чем у основного маршрута к той же сети, поэтому маршрутизатор начинает пользоваться им, только когда основной маршрут пропадает, например при отказе канала.

Согласно сценарию, маршрутизатор Edge_Router подключает две локальные сети компании, LAN 1 и LAN 2, к двум интернет-провайдерам: основной канал ведет к маршрутизатору ISP1, резервный — к маршрутизатору ISP2. За провайдерами находится сервер Customer-Server важного клиента компании, к которому пользователи обращаются чаще всего. Вам, сетевому администратору, нужно настроить статические маршруты IPv4 и IPv6 на маршрутизаторах Edge_Router и ISP1 так, чтобы компьютеры обеих локальных сетей связывались с сервером через ISP1, а при отказе основного канала — через ISP2. Это лабораторная работа на проверку навыков: в ней перечислены требования к результату, а команды для их выполнения вы выбираете сами.

## Задачи лабораторной работы

- Настроить статические маршруты IPv4 по умолчанию на маршрутизаторе Edge_Router
- Настроить статические маршруты IPv6 по умолчанию на маршрутизаторе Edge_Router
- Настроить статические маршруты IPv4 к локальным сетям компании на маршрутизаторе ISP1
- Настроить статические маршруты IPv6 к локальным сетям компании на маршрутизаторе ISP1
- Настроить статические маршруты узла к серверу Customer-Server на маршрутизаторе Edge_Router
- Проверить связь с сервером и переход на резервный канал

## Описание топологии

Топология состоит из маршрутизаторов Edge_Router, ISP1 и ISP2, коммутаторов LAN_1, LAN_2 и ISP_LAN, компьютеров PC-A и PC-B и сервера Customer-Server.
