## Описание сценария

По протоколу Telnet администратор управляет сетевым устройством удаленно, но все данные сеанса, в том числе пароли, передаются открытым текстом, и их может прочитать любой, кто перехватит трафик. Протокол SSH решает ту же задачу безопасно: он шифрует весь сеанс, а при входе проверяет учетную запись пользователя. Пароли в самой конфигурации устройства тоже не должны храниться открытым текстом, иначе их увидит каждый, кто выведет конфигурацию на экран.

Согласно сценарию, коммутатором S1 управляют с компьютера администратора PC1 по протоколу Telnet, а пароли в конфигурации коммутатора записаны открытым текстом. Вам, сетевому администратору, нужно зашифровать пароли в конфигурации, настроить на коммутаторе протокол SSH с локальной учетной записью administrator, запретить подключение по протоколу Telnet и убедиться, что коммутатором можно управлять только по SSH.

## Задачи лабораторной работы

- Подключиться к коммутатору S1 по протоколу Telnet и проверить, как хранятся пароли
- Зашифровать пароли в конфигурации коммутатора S1
- Настроить протокол SSH на коммутаторе S1
- Проверить, что коммутатор S1 доступен удаленно только по протоколу SSH
