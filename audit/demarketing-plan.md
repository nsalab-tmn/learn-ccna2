# План очистки учебного контента CCNA2 от вендора — по приоритетам

Основа — карта `audit/vendor-mentions.csv`. Разметка по этому плану — `audit/demarketing-tiers.csv`: каждой строке карты, которую видит обучающийся, присвоены ярус и пункт плана. `id` совпадает с картой, контекст (`excerpt`, `note`) берётся оттуда.

## Что входит и что нет

**Входит** — только то, что видит обучающийся:
- лекции (`README.md` тем);
- квизы и экзамены (`learn-metadata.json`: вопросы, варианты, пояснения);
- руководства лаб (`README.md` лаб и вопросы `answerSchema`);
- иллюстрации (SVG из Figma) и растры в `assets/`;
- блоки команд и выводов CLI;
- тег курса.

**Не входит:**
- имена репозиториев, каталогов и файлов, id ассетов, страницы Figma;
- служебные документы (`migration-instructions.md`, `ccna2-labs.md`, `readme-assets/`, `packet-tracer-source-files/`);
- `deploy/` и `assessment/`;
- видео — пересобираются отдельно; 16 строк встраиваний помечены `X`;
- синтаксис команд в стиле IOS: `show etherchannel`, `spanning-tree portfast`, `no ip cef`, `switchport nonegotiate` и т. п.

## Как пользоваться `demarketing-tiers.csv`

Колонки: `id`, `tier` (1, 2, 3, K, X), `item` (пункт плана), `hint` (для 1.2 — какой шаблон применить; для 2.8 — с каким растром связан текст), `kind` (lecture / quiz / pt-lab / nopt-lab), `surface`, `locator`, `term`.

Исполнителю достаточно отфильтровать по `item` — например, «1.2» и `hint` = «квалификатор устройства». Полный контекст строки берётся из `vendor-mentions.csv` по `id`.
