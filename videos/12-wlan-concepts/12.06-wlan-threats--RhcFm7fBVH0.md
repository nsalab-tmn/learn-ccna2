## Цель для обучающегося

Обучающийся должен уметь перечислить четыре класса угроз WLAN (перехват данных → шифрование; беспроводные нарушители → аутентификация; DoS; вредоносные AP → мониторинг), назвать три источника DoS (ошибки конфигурации, умышленные помехи/перегрузка AP, случайные помехи от микроволновок, радионянь, беспроводных телефонов — особенно в 2,4 ГГц) и меры (hardening, пароли, бэкапы, изменения в нерабочее время, переход на 5 ГГц), объяснить, чем опасна rogue AP (захват MAC и пакетов, доступ к проводной сети, MITM) и как её выявлять (rogue-политики WLC + мониторинг спектра), и описать атаку «злой близнец» (evil twin: та же SSID, открытая аутентификация, более сильный сигнал, трафик проксируется через атакующего).

Текст темы (12.6.2–12.6.5) содержит те же пункты и те же рисунки, причём подробнее (например, «личная точка доступа» Windows как rogue AP). Видео нового не добавляет; из деталей на экране — конкретика evil-twin-слайда: кафе «Bob's Latte», выноска «SSID: Bob-Latte, Authentication: Open, Channel: 6» у ноутбука злоумышленника; страница WLC `SECURITY › Wireless Protection Policies › Rogue Policies` с полями Rogue Detection Security Level (Low/High/Critical/Custom), Rogue Location Discovery Protocol, Expiration Timeout for Rogue AP and Rogue Client entries, Validate rogue clients against AAA, Rogue Detection Report Interval, Auto Contain (Auto Containment Level, Rogue on Wire, Using our SSID, Valid client on Rogue AP, AdHoc Rogue AP).

## Предложение по пересборке

**Формат:** `текст + иллюстрация` — содержание полностью покрыто текстом 12.6.2–12.6.5 с теми же рисунками. Единственный кандидат на движение — анимация Figma ≤ 45 с «evil twin»: два сигнала с одинаковым SSID, клиент выбирает более сильный, трафик идёт через злоумышленника к настоящей точке и обратно. Остальное — текст.

Сцены для генератора (опциональная анимация «Злой близнец»):

1. Кафе: легитимная AP «Bob-Latte, Open, ch 6» над входом, клиент с ноутбуком, облако Internet → «Открытая сеть кафе».
2. Появляется ноутбук злоумышленника с выноской «SSID: Bob-Latte, Open, ch 6» и кольцами сигнала сильнее (ближе к клиенту) → «Злоумышленник поднимает точку с тем же именем».
3. На экране клиента список сетей: две записи «Bob-Latte», верхняя (сильнее) выделяется; клиент подключается к ней → «Клиент выбирает более сильный сигнал».
4. Конверты данных: клиент → злоумышленник (значок «глаз»/копия) → легитимная AP → Internet; ответ тем же путём → «Весь трафик проходит через посредника».
5. Ярлыки: «WPA2/WPA3 вместо Open», «VPN на клиенте», «WLC: rogue-политики + мониторинг спектра» → «Защита».

Ассеты: фасад кафе, AP/роутер, два ноутбука (пользователь, злоумышленник с черепом), кольца сигнала, список Wi-Fi-сетей на экране клиента, конверты.

Для симулятора: CLI не требуется; скриншот Rogue Policies можно использовать как макет страницы WLC в будущем WLC-симуляторе (поля перечислены выше).
