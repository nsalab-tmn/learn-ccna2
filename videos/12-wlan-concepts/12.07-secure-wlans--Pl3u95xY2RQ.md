## Цель для обучающегося

Обучающийся должен понимать, почему сокрытие SSID и фильтрация MAC — лишь «отсев любопытных» (SSID легко узнать, MAC подделать), различать открытую аутентификацию и аутентификацию с общим ключом, расположить WEP → WPA (TKIP) → WPA2 (AES) → WPA3 (PMF) по стойкости, выбрать для дома WPA2 Personal (PSK) + AES, а для предприятия — WPA2 Enterprise с RADIUS-сервером (IP сервера, UDP 1812/1813 или 1645/1646, общий ключ между AP и RADIUS).

Текст темы (12.7.2–12.7.8) покрывает всё это подробнее (RC4, MIC, CCMP, 802.1X/EAP, WPA3 SAE/OWE/DPP) с теми же скриншотами роутера. Видео добавляет только наглядные значения в GUI: выпадающий список Security Mode (Disabled / WEP / WPA Personal / WPA Enterprise / WPA2 Personal / WPA2 Enterprise), Encryption (AES / TKIP), Key Renewal 3600 s, поля RADIUS Server `10.10.10.100`, RADIUS Port `1645`, Shared Key — и разговорное объяснение, что домашние устройства (планшеты, смартфоны, Blu-ray, телевизоры) используют один и тот же PSK, а WPA2 Enterprise «можно и дома».

## Предложение по пересборке

**Формат:** `текст + иллюстрация` — текст 12.7.2–12.7.8 полнее видео и содержит те же скриншоты. Если нужен короткий ролик-открытие темы — анимация Figma ≤ 45 с «лестница стойкости» (Open → WEP → WPA/TKIP → WPA2/AES → WPA3/PMF) с переходом в «Personal (PSK) vs Enterprise (RADIUS: IP, 1812/1813, shared key)». Отдельно: эти же экраны роутера станут упражнением симулятора домашнего роутера (см. 13.01), поэтому поля стоит зафиксировать в макете.

Сцены для генератора (опциональная анимация):

1. **Стены прозрачны** → дом/офис, сигнал Wi-Fi выходит за стены к ноутбуку снаружи → «Беспроводная сеть — как розетка на улице.»
2. **Старые меры** → ярлыки «скрыть SSID», «MAC-фильтр»; рядом злоумышленник с подписями «SSID всё равно виден в probe/ассоциации», «MAC подделан» → «Отсев любопытных, не защита.»
3. **Дерево аутентификации** → Open (без пароля) / Shared Key → WEP ✗, WPA (TKIP) △, WPA2 (AES) ✓, WPA3 (PMF) ✓✓ → «Выбираем WPA2, а когда доступно — WPA3.»
4. **Дом vs предприятие** → слева роутер + PSK, одинаковый ключ на всех устройствах; справа AP ↔ RADIUS `10.10.10.100`, UDP 1812/1813, «shared key» между ними; пользователи с логином/паролем → «Personal — один общий пароль; Enterprise — учётные записи на RADIUS.»

Ассеты: дом с «просвечивающим» сигналом; дерево методов; макет страницы *Wireless Security* домашнего роутера (Security Mode, Encryption, Passphrase, Key Renewal, RADIUS Server, RADIUS Port, Shared Key) — для 2.4 GHz / 5 GHz-1 / 5 GHz-2; иконка RADIUS-сервера.

Для симулятора (GUI домашнего роутера, не CLI) — значения из видео:

  Security Mode : WPA2 Personal            (список: Disabled | WEP | WPA Personal | WPA Enterprise | WPA2 Personal | WPA2 Enterprise)
  Encryption    : AES                      (список: AES | TKIP)
  Passphrase    : <PSK>
  Key Renewal   : 3600 seconds

  Security Mode : WPA2 Enterprise

  RADIUS Port   : 1645                     (стандарт: 1812 auth / 1813 acct; альтернатива 1645/1646)
