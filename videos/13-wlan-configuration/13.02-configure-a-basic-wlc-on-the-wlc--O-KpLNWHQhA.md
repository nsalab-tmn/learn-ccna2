## Цель для обучающегося

Обучающийся должен уметь на WLC создать и включить базовую WLAN: зайти на management-адрес контроллера из management-VLAN, прочитать сводку (сети / точки / клиенты / rogue), перейти в Advanced, создать WLAN (Profile Name и SSID `Wireless_LAN`, ID 1), включить её (Status Enabled), привязать к пользовательскому интерфейсу `user_wlan` (VLAN 5), а не к `management`, задать Layer 2 Security WPA+WPA2 с WPA2 Policy/AES и аутентификацией PSK (вместо 802.1X по умолчанию) с ключом, применить и убедиться по Network Summary и Monitor › Clients, что клиент подключился и получил адрес из сети пользователей (192.168.5.x), а не из management (192.168.200.x).

Текст темы (13.2.2–13.2.6) приводит ту же топологию, таблицу адресации, скриншоты входа, Network Summary, Access Points (с CLI AP1: ping, `show interface wired 0`), Advanced › Summary и шаги 1–7 создания WLAN с теми же экранами. Видео добавляет: объяснение, **зачем** два VLAN на транке к WLC (management vs user traffic) и почему WLAN нельзя оставлять на интерфейсе management; точную последовательность кликов в Security › Layer 2 (снять 802.1X, поставить PSK, PSK Format ASCII, ключ); чтение страницы Clients (MAC, IP 192.168.5.2, AP1, профиль/SSID).

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер) ~4:30 на макете GUI WLC (dashboard + классический Advanced-интерфейс) с мини-топологией в углу, подсвечивающей активный VLAN/устройство. Сценарий — прототип упражнения симулятора «WLC: базовая WLAN» (GUI). Видео 13.03 (четыре ролика) продолжают эту же топологию — делать единым набором макетов.

Сцены для генератора:

1. **Топология** → R1 — S1 — WLC (транк G1), AP1 (PoE, Fa0/1), ноутбук, PC-B (Fa0/6), PC-A «RADIUS/SNMP» (R1 F0/0); подписи VLAN 1 mgmt 192.168.200.0/24, VLAN 5 user 192.168.5.0/24; транк подсвечивается с двумя «полосами» → «Транк к WLC несёт две VLAN: управление и пользовательский трафик.»
2. **Вход** → браузер PC-B → `192.168.200.254` → Login → `admin` / `Cisco123` → «Заходим из management-VLAN на management-адрес контроллера.»
3. **Dashboard** → Network Summary: 0 сетей, 1 AP (AP1), 0 клиентов, 79 rogue → «Точка присоединилась, но предлагать ей нечего.»
4. **Advanced › Summary** → картинка 3504 с одним зелёным портом; раздваивается на интерфейсы `management (VLAN 1)` и `user_wlan (VLAN 5)` → «Порт один, интерфейсов два.»
5. **Создание** → WLANs › Create New › Go → Profile Name / SSID `Wireless_LAN`, ID 1 → Apply → «Профиль и имя сети.»
6. **General** → Status ☑ Enabled; Interface `management` → `user_wlan` (подсветка опасности при management) → «Включаем и уводим пользователей из management-VLAN.»
7. **Security › Layer 2** → WPA+WPA2; WPA2 Policy ☑, AES ☑; 802.1X ☐ → PSK ☑; ASCII; ключ → Apply → «WPA2/AES с общим ключом; 802.1X — в 13.03.»
8. **Проверка** → Home: 1 сеть, 1 клиент → Monitor › Clients: MAC, `192.168.5.2`, AP1, Wireless_LAN → на топологии ноутбук получает адрес из VLAN 5 → «Клиент в пользовательской сети, а не в management.»

Ассеты: топология (см. выше); макеты экранов WLC: Login, Dashboard/Network Summary, Monitor › Summary (с картинкой 3504), WLANs list, WLANs › New, WLANs › Edit General, Security › Layer 2 (с блоком Authentication Key Management), Monitor › Clients.
