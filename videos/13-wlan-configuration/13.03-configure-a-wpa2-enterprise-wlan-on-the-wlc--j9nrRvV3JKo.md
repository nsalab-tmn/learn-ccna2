## Цель для обучающегося

Обучающийся должен понимать, что внутренний DHCP-сервер WLC — не замена DHCP для сотен пользователей (это делает маршрутизатор/выделенный сервер), а средство выдать адреса **управляющим** устройствам в management-сети: lightweight-точкам доступа, присоединяющимся к контроллеру, и, возможно, management-ПК; и уметь создать область (scope): имя → начальный и конечный адрес пула, сеть и маска, время аренды, маршрутизатор по умолчанию (R1 192.168.200.1, а не сам WLC .254) → Status Enabled → Apply → проверить в списке.

Текст темы (13.3.9) описывает те же пять шагов на тех же экранах (имя `Wireless_Management`, пул .240–.249). Видео добавляет: обоснование «для кого» внутренний DHCP (AP и management-ПК, до 20 точек при пуле на 21 адрес), значения `MGMT_IPs`, пул `192.168.200.220 – 192.168.200.240`, Lease 86400 с по умолчанию, и явное объяснение, что Default Router — это точка выхода из сети (R1), «а не мы на 200.254 — мы контроллер».

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер) ~2:00 на макетах GUI WLC (Controller › Internal DHCP Server › DHCP Scopes: список, New, Edit). Третий эпизод серии «WLC: WPA2 Enterprise» (самый короткий; можно объединить с 13.3.5 в один ролик «интерфейс VLAN 5 + область DHCP»). Сценарий — упражнение симулятора WLC.

Сцены для генератора:

1. **Кому DHCP от WLC** → топология: от WLC к AP1 и PC-B конверты «DHCP» в management-сети 192.168.200.0/24; к ноутбуку в VLAN 5 конверт «DHCP» от R1 → «Контроллер раздаёт адреса только управляющим устройствам; пользователям — маршрутизатор.»
2. **Controller › Internal DHCP Server › DHCP Scope** → пустой список → New → Scope Name `MGMT_IPs` → Apply → строка `0.0.0.0 – 0.0.0.0 · 1 d` → «Сначала только имя.»
3. **Edit** → Pool Start `192.168.200.220`, Pool End `192.168.200.240`, Network `192.168.200.0`, Netmask `255.255.255.0`, Lease `86400`, Default Routers `192.168.200.1` (подсветка: «не .254 — это сам WLC»), Status `Enabled` → Apply → «Пул на 21 адрес, шлюз — R1.»
4. **Проверка** → список: `MGMT_IPs · 192.168.200.220 – 192.168.200.240 · 1 d · Enabled` → «Область включена.»

Ассеты: макеты DHCP Scopes (список / New / Edit); топология с конвертами DHCP.

Сессия для симулятора (GUI):

```
WLC GUI › [Advanced] › CONTROLLER › Internal DHCP Server › DHCP Scope › [New...]
  Scope Name = MGMT_IPs › [Apply]
DHCP Scopes › MGMT_IPs › Edit
  Pool Start Address = 192.168.200.220 ; Pool End Address = 192.168.200.240
  Network = 192.168.200.0 ; Netmask = 255.255.255.0 ; Lease Time (seconds) = 86400
  Default Routers = 192.168.200.1 ; DNS Domain Name = — ; DNS Servers = 0.0.0.0 ; Netbios Name Servers = 0.0.0.0
  Status = Disabled → Enabled › [Apply]
DHCP Scopes → MGMT_IPs · 192.168.200.220 – 192.168.200.240 · 1 d · Enabled
```
