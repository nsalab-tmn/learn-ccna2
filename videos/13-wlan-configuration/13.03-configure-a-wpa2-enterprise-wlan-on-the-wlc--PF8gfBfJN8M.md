## Цель для обучающегося

Обучающийся должен уметь собрать вместе всё, что сделано в 13.3.1–13.3.8: создать WLAN `CompanyName` (ID 2), включить её и привязать к пользовательскому интерфейсу `vlan5_userdata`, убедиться, что по умолчанию стоит WPA2 с AES и управление ключами 802.1X (не переключать на PSK, как в 13.2), на вкладке AAA Servers назначить ранее добавленный RADIUS-сервер `172.16.1.254:1812` (accounting — None), применить, проверить в списке WLAN (`[WPA2][Auth(802.1X)]` против `[WPA2][Auth(PSK)]` у Wireless_LAN) — и, главное, **проверить цепочку WLC → RADIUS из CLI контроллера** командами `test aaa radius … wlan-id 2` / `test aaa show radius`.

Текст темы (13.3.11) даёт те же шесть шагов GUI со скриншотами (там WLAN ID 5 и интерфейс `vlan5`; в видео ID 2 и `vlan5_userdata`). Видео добавляет: объяснение роли каждой стороны (сотрудник вводит логин/пароль → AP → WLC → RADIUS на PC-A → allow/deny), выбор сервера в выпадающем списке «IP:172.16.1.254, Port:1812», и целиком отсутствующую в тексте проверку из консоли WLC: `show aaa auth` (порядок local → radius), `test aaa radius username bob password hello wlan-id 2` (список атрибутов запроса, «test radius auth request successfully sent»), `test aaa show radius` (Radius Server 172.16.1.254 · Retry 1 · Status Success; Authentication Response: Result Code: Success).

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер) ~4:00: макеты GUI WLC (WLANs › New, Edit General, Security › Layer 2, Security › AAA Servers, список WLAN) + терминал WLC. Финал серии «WLC: WPA2 Enterprise»; рекомендуемая компоновка серии — один ролик ~10 мин (13.3.1 → 13.3.5 → 13.3.8 → 13.3.10) с общей топологией. Для симулятора это самый ценный из четырёх: он даёт и GUI-сценарий, и CLI-проверку с детерминированным выводом.

Сцены для генератора:

1. **Цепочка аутентификации** → топология: ноутбук «Company Employee» → AP1 → WLC → PC-A (RADIUS); конверты «bob / hello» вперёд и «Access-Accept» назад → «Логин и пароль проверяет RADIUS, а не общий ключ.»
2. **WLANs › New** → Profile Name / SSID `CompanyName`, ID `2` → Apply → «Новая сеть.»
3. **General** → Status ☑; Interface `vlan5_userdata` (подсветка: VLAN 5 = данные, VLAN 1 = management — не трогать) → «Включаем и отправляем пользователей в VLAN 5.»
4. **Security › Layer 2** → WPA2 Policy ☑, AES ☑, 802.1X ☑ (оставить!) ; рядом «ghost»-вариант с PSK из 13.2 перечёркнут → «Для Enterprise оставляем 802.1X.»
5. **AAA Servers** → Server 1: список → `IP:172.16.1.254, Port:1812`; Accounting None → Apply → «Куда слать запросы — RADIUS из 13.3.1.»
6. **Список WLAN** → две строки: Wireless_LAN `[WPA2][Auth(PSK)]`, CompanyName `[WPA2][Auth(802.1X)]` → «Две сети — два способа аутентификации.»
7. **Консоль WLC** → `show aaa auth`; `test aaa radius username bob password hello wlan-id 2`; `test aaa show radius` → подсветка `Status Success`, `Result Code: Success` → «Контроллер сам проверяет связку с RADIUS.»

Ассеты: топология (ноутбук «Company Employee»); макеты экранов WLC (см. выше); терминал `(Cisco Controller) >` с типовым выводом.

Сессия для симулятора (GUI + CLI):

