## Цель для обучающегося

Обучающийся должен понимать, зачем WLC нужны два внешних сервера — SNMP-приёмник трапов (централизованный журнал событий) и RADIUS (индивидуальные логин/пароль вместо общего PSK), — и уметь прописать их на контроллере: trap receiver с community-строкой и адресом сервера; RADIUS-сервер аутентификации с адресом, общим секретом (одинаков на WLC и на сервере), портом 1812; а затем проверить достижимость сервера пингом прямо из GUI контроллера.

Текст темы (13.3.2–13.3.4) даёт то же самое со скриншотами (SNMP: Management › SNMP › Trap Receivers › New; RADIUS: Security › RADIUS › Authentication › New; список серверов после Apply). Видео добавляет: топологию с подписью сети серверов 172.16.1.0/24 и адресом PC-A `172.16.1.254`; конкретные значения (community `CCNAv7`, shared secret `Testing123`); объяснение, что shared secret — пароль между WLC и RADIUS, а не для пользователей; и проверку ping из выпадающего меню строки сервера (3 отправлено / 3 получено, 100 %), которой в тексте нет.

## Сценарий

**Топология** (слайд 0:00–2:15): та же, что в 13.2 — **PC-A «RADIUS/SNMP Server»** в сети `172.16.1.0/24` (подпись «Network – 172.16.1.0/24» над PC-A, IP `.254`) ↔ R1 F0/0; R1 F0/1 (802.1q trunk) ↔ S1 F0/5; S1 F0/6 ↔ PC-B; S1 F0/18 (802.1q trunk) ↔ WLC G1; S1 F0/1 (802.1q trunk, PoE) ↔ AP1 ~ ноутбук. «VLAN 1 – Management Network – 192.168.200.0/24», «VLAN 5 – User Network – 192.168.5.0/24».

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер) ~3:00 на тех же макетах GUI WLC, что в 13.02 (добавить страницы Management › Summary, SNMP Trap Receiver › New, Security › AAA, RADIUS Authentication Servers › New и список). Часть серии «WLC: WPA2 Enterprise» (четыре видео темы 13.3 → один связный ролик ~10 мин или четыре коротких). Сценарий — упражнение симулятора WLC.

Сцены для генератора:

1. **Топология** → подсветка PC-A «RADIUS/SNMP 172.16.1.254» и WLC; от WLC к PC-A конверт «SNMP trap», от ноутбука через AP1 → WLC → PC-A конверт «логин/пароль?» и обратно «OK» → «Два сервера на одном ПК: приёмник трапов и проверка учётных записей.»
2. **PSK vs RADIUS** → слева три клиента с одним ключом `Cisco123`; справа три клиента с разными логинами и база на PC-A → «Общий ключ — для дома; на предприятии — у каждого свой логин.»
3. **Management › SNMP › Trap Receivers › New** → Community `CCNAv7`, IP `172.16.1.254`, Status Enable → Apply → строка в списке → «Куда слать трапы и с каким community.»
4. **Security › AAA › RADIUS › Authentication › New** → Server IP `172.16.1.254`, Shared Secret `Testing123` ×2, Port `1812`, Server Status Enabled → Apply → строка в списке → «Секрет — между WLC и сервером, пользователи его не знают.»
5. **Ping из GUI** → меню ▾ в строке сервера → Ping → «3/3, 100 %» → «Контроллер достигает сервер — можно переходить к WPA2 Enterprise.»

Ассеты: топология 13.2 с подписью сети 172.16.1.0/24; макеты: Management › Summary, SNMP Trap Receiver (список + New), Security › AAA › General, RADIUS Authentication Servers (список + New), окно результата Ping.

Сессия для симулятора (GUI):

```

  → список: CCNAv7 · 172.16.1.254 · Enable · Disable

  → список: [x] Network User · [x] Management · Index 1 · 172.16.1.254 · 1812 · IPSec Disabled · Admin Status Enabled
```
