## Цель для обучающегося

Обучающийся должен уметь самостоятельно выполнить первичную настройку SOHO-роутера: физически подключить ПК к LAN-порту и модем к WAN-порту, зайти в GUI по адресу по умолчанию с заводскими учётными данными, сменить пароль администратора, проверить/изменить тип WAN-подключения (DHCP от провайдера) и источник DNS, параметры LAN (адрес роутера, маска, DHCP-пул: начальный адрес и число клиентов, срок аренды, DNS для клиентов), включить радио, выбрать режим 802.11 и канал, переименовать SSID, ограничить число клиентов, задать WPA2-Personal с AES и парольной фразой, затем подключить клиент.

Текст темы (13.1.2–13.1.5) описывает те же шаги на скриншотах другого роутера (Packet Tracer / Linksys-подобный GUI: admin/admin, 192.168.0.1, вкладки Setup/Wireless/Administration), а в 13.1.6–13.1.9 добавляет mesh, NAT, QoS, port forwarding — их в видео нет. Видео добавляет: реальный порядок действий «из коробки» (принудительная смена пароля при первом входе с требованиями к сложности и индикатором стойкости; разлогин после смены), точные экраны RV130W (`Networking › WAN`, `Networking › LAN › LAN Configuration`, `Wireless › Basic Settings`, `Security Settings`), варианты выпадающих списков (DNS Server Source: Get Dynamically from ISP / Use OpenDNS / Use these DNS Servers; Wireless Network Mode: B/G/N-Mixed, B/G-Mixed, B-Only, G-Only, N-Only, G/N-Mixed; канал Auto / 1–2.412 GHz … 11–2.462 GHz; Security Mode: Disabled, WEP, WPA-Personal, WPA-Enterprise, WPA2-Personal, WPA2-Personal Mixed, WPA2-Enterprise, WPA2-Enterprise Mixed) и совет отключать радио, если роутер работает только как маршрутизатор/брандмауэр, а Wi-Fi дают отдельные точки доступа.

## Сценарий

Устройство: **Cisco RV130W Wireless-N VPN Firewall** (чёрный корпус, две внешние антенны, на задней панели 4 × LAN, 1 × WAN, питание). Браузер: Firefox, `https://192.168.1.1`. Логин GUI: `cisco` / `cisco` (далее — новый пароль). В заголовке GUI: «RV130W Wireless-N VPN Firewall», справа «cisco (admin) · Language: English · Log Out · About · Help». Левое меню: Getting Started, Status, Networking, Wireless, Firewall, VPN, QoS, Administration.

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер) ~5:00 на макете GUI домашнего роутера (наш «SOHO-роутер» в симуляторе) + короткая вставка-анимация физических портов. Этот сценарий — прямой прототип интерактивного упражнения симулятора «первичная настройка домашнего роутера» (GUI, не CLI): те же экраны, те же поля.

Сцены для генератора:

1. **Кабели** → схема: ПК —(Ethernet)— LAN-порт 1 роутера; модем —(оранжевый)— WAN; обе вставки подсвечиваются → «ПК — в любой LAN-порт, модем — в WAN.»
2. **Вход** → браузер `http://192.168.1.1` → форма Username/Password; вводим `cisco`/`cisco` → «Адрес и учётные данные по умолчанию — из документации; они известны всем, поэтому…»
3. **Смена пароля** → экран Change Password с требованиями (≥ 8 символов, ≥ 3 класса, ≠ имени, ≠ старому), индикатор стойкости; Save → разлогин → повторный вход → «…первым делом меняем пароль администратора.»
4. **WAN** → Networking › WAN: Internet Connection Type = Automatic Configuration – DHCP; DNS Server Source: список из трёх вариантов → «Адрес от провайдера по DHCP; DNS — от провайдера или свои.»
5. **LAN / DHCP** → Networking › LAN: Local IP 192.168.1.1/24; DHCP Enable; Starting 100; Max Users 50 → 100; диапазон пересчитывается 192.168.1.100–199; Lease 1440; DNS Server: Use DNS Proxy / from ISP / as Below → «Роутер сам раздаёт адреса; меняем размер пула.»
6. **Radio + режим + канал** → Wireless › Basic Settings: Radio ☑; Mode B/G/N-Mixed → G/N-Mixed; Channel Auto (список 1…11) → «Без устаревшего B сеть быстрее; канал — авто или вручную 1/6/11.»
7. **SSID** → в таблице Edit: ciscosb1 → businessconnect, Broadcast ☑, Max clients 16 → 40; Save → плашка «saved successfully» → «Имя сети и лимит клиентов.»
8. **Безопасность** → Edit Security Mode: WPA2-Personal, AES, ключ (индикатор Below Minimum → Secure), Key Renewal 3600; Save → «WPA2-Personal с AES; Mixed — только ради старых устройств.»
9. **Клиент** → панель Wi-Fi Windows: businessconnect → ввод ключа → Connected → «Проверяем подключение.»

Ассеты: фото/рендер SOHO-роутера с задней панелью (4 × LAN, WAN, питание); макеты экранов GUI: Login, Change Password, Getting Started, WAN Configuration, LAN Configuration, Wireless Basic Settings (с Wireless Table на 4 SSID), Security Settings; панель Wi-Fi Windows.
