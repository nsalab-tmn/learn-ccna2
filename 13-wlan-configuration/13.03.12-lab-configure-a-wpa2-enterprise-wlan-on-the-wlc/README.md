## Описание сценария

Общий ключ WPA2-PSK плохо масштабируется: он один на всех, и его смена означает перенастройку каждого клиента. В сети предприятия сеть WLAN защищают по WPA2 Enterprise: контроллер передает учетные данные пользователя серверу RADIUS по протоколу 802.1X, у каждого пользователя своя учетная запись, а активность регистрируется на сервере. Для каждой сети WLAN на контроллере создают динамический интерфейс с номером VLAN, адресом, шлюзом и DHCP-сервером этой сети. Внутренний DHCP-сервер контроллера с областью адресов сети управления нужен, чтобы облегченные точки доступа получили адрес и присоединились к контроллеру, а получатель SNMP-трапов — чтобы контроллер сообщал о событиях серверу управления.

Согласно сценарию, вы уже настроили на контроллере сеть WLAN с защитой WPA2-PSK для небольшого офиса, а теперь вас просят сделать то же для крупного предприятия с проверкой пользователей на сервере RADIUS. Контроллер WLC-1 пока настроен только интерфейсом управления, и точка доступа LAP-1 ждет адреса. Вам нужно создать на контроллере интерфейс WLAN-5, подключить сервер RADIUS-Server, создать сеть WLAN с защитой WPA2 Enterprise, настроить область DHCP сети управления и получателя SNMP-трапов, а затем подключить ноутбук Wireless-Host по профилю с учетной записью пользователя и проверить связь.

## Задачи лабораторной работы

- Создать на контроллере WLC-1 интерфейс WLAN-5 и подключить сервер RADIUS
- Создать сеть WLAN с защитой WPA2 Enterprise
- Настроить область DHCP сети управления и получателя SNMP-трапов
- Подключить ноутбук Wireless-Host по профилю WPA2-Enterprise и проверить связь

## Описание топологии

Топология состоит из маршрутизатора R-1 с сервером RADIUS-Server, коммутатора SW-1, к которому подключены компьютер Admin-PC, контроллер WLC-1 и точка доступа LAP-1, и ноутбука Wireless-Host в зоне покрытия точки доступа.

<!-- figure: topology -->

Схема сети открывается по ссылке «Адрес лаборатории» после развертывания лабораторной работы. Маршрутизатор R-1 и коммутатор SW-1 настроены, их консоли со схемы не открываются. Контроллер WLC-1 настраивается через его веб-интерфейс в браузере компьютера Admin-PC, а точка доступа LAP-1 управляется контроллером. Щелчок по компьютеру или ноутбуку открывает окно устройства: на вкладке «Рабочий стол» в нем есть приложения «Командная строка», «IP-конфигурация» и «Веб-браузер», а на ноутбуке — «Беспроводная сеть». Пошаговое описание работы открывается на той же странице, в панели «Сценарий».
