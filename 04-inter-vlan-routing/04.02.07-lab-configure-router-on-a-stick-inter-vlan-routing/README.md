## Описание сценария

Узлы разных сетей VLAN находятся в разных IP-сетях, и обмениваться пакетами они могут только через маршрутизатор. При router-on-a-stick (маршрутизация между VLAN через один магистральный канал) маршрутизатор подключают к коммутатору одним кабелем, а на его физическом интерфейсе создают по подинтерфейсу для каждой сети VLAN. IP-адрес подинтерфейса служит шлюзом по умолчанию для узлов своей сети VLAN. Коммутатор передает маршрутизатору кадры всех сетей VLAN по магистральному каналу (trunk) с тегами 802.1Q, и по тегу маршрутизатор определяет, какому подинтерфейсу адресован кадр.

Согласно сценарию, в небольшом офисе компьютеры двух отделов разделены на коммутаторе S1 по сетям VLAN 10 и 30, и сотрудникам отделов нужно обмениваться данными друг с другом. В офисе есть один маршрутизатор R1, подключенный к коммутатору одним кабелем. Вам, сетевому администратору офиса, нужно создать сети VLAN на коммутаторе и назначить им порты компьютеров, настроить на маршрутизаторе подинтерфейсы для обеих сетей VLAN, настроить магистральный канал между коммутатором и маршрутизатором и проверить связь между компьютерами разных сетей VLAN.

## Задачи лабораторной работы

- Проверить связь между компьютерами PC1 и PC3 до настройки сети
- Создать сети VLAN 10 и 30 и назначить им порты коммутатора S1
- Настроить подинтерфейсы маршрутизатора R1 для сетей VLAN 10 и 30
- Настроить магистральный канал между коммутатором S1 и маршрутизатором R1
- Проверить маршрутизацию между сетями VLAN

## Описание топологии

Топология состоит из маршрутизатора R1, коммутатора S1 и компьютеров PC1 и PC3: маршрутизатор и оба компьютера подключены к коммутатору S1.
