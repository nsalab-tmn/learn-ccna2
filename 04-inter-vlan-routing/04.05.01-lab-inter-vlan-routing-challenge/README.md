## Описание сценария

Сети VLAN разделяют узлы, подключенные к одному коммутатору, на отдельные сети, и узлы разных сетей VLAN не обмениваются данными напрямую. Чтобы они могли связываться друг с другом, нужна маршрутизация между VLAN. В схеме router-on-a-stick (маршрутизация между VLAN через один магистральный канал) маршрутизатор подключают к коммутатору одним магистральным каналом (trunk). На физическом интерфейсе маршрутизатора создают по подинтерфейсу для каждой сети VLAN, и подинтерфейс с инкапсуляцией 802.1Q становится шлюзом по умолчанию для узлов своей сети VLAN.

Согласно сценарию, учебный корпус колледжа подключается к сети главного офиса через маршрутизатор R1, а за маршрутизатором главного офиса HQ находится сервер Server. В корпусе работают преподаватели и сотрудники, учатся студенты и бывают гости, и для каждой группы нужна своя сеть VLAN, а для управления коммутатором S1 — отдельная сеть VLAN управления. Вам нужно настроить на коммутаторе S1 сети VLAN, порты, магистральный канал к маршрутизатору R1 и интерфейс управления, а на маршрутизаторе R1 — маршрутизацию между VLAN, чтобы компьютеры всех групп, коммутатор и маршрутизатор обменивались данными друг с другом и с сервером. Это лабораторная работа на проверку навыков: в ней перечислены требования к результату, а команды для их выполнения вы выбираете сами.

## Задачи лабораторной работы

- Создать сети VLAN на коммутаторе S1 и назначить им порты
- Настроить магистральный канал между коммутатором S1 и маршрутизатором R1
- Настроить интерфейс управления коммутатора S1
- Настроить маршрутизацию между VLAN на маршрутизаторе R1
- Проверить связь между компьютерами, коммутатором, маршрутизатором и сервером

## Описание топологии

Топология состоит из коммутатора S1, маршрутизаторов R1 и HQ, сервера Server и трех компьютеров PC1–PC3: компьютеры подключены к коммутатору S1, коммутатор — к маршрутизатору R1, маршрутизатор R1 — к маршрутизатору HQ, а сервер — к маршрутизатору HQ.

Схема сети открывается по ссылке «Адрес лаборатории» после развертывания лабораторной работы. Щелчок по коммутатору S1 или маршрутизатору R1 на схеме открывает его консоль. Маршрутизатор главного офиса HQ уже настроен, и его консоль со схемы не открывается. Щелчок по компьютеру открывает окно устройства: на вкладке «Рабочий стол» в нем есть приложение «Командная строка». Требования к работе открываются на той же странице, в панели «Сценарий».
